Экспорт в разработке

Функция экспорта логов рассылок находится в активной разработке.
Скоро вы сможете выгружать данные в различных форматах для анализа.

Планируемые форматы экспорта:

📋
CSV
Для Excel и Google Sheets
📈
XLSX
Форматированные таблицы
📄
PDF
Для отчетов и презентаций
📊
JSON
Для разработчиков и API
