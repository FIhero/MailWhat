# Проект по создании почты для рассылки

### Что здесь есть на данном коммите:
- Страницы: Главная, Уведомлений, Клиентов, Рассылок, Логов, формы создания/регистрации клиентов, сообщений, рассылок
- Меню для перехода между страницами сайта
- Адаптивный дизайн для мобильных устройств

## Часть 1 - Рассылка

### Главная
- Здесь есть приветствие
- Отображается статистика в зависимости от роли:
  - Пользователь - количество всего рассылок, количество активных рассылок, количество созданных сообщений
  - Менеджер - количество рассылок, количество активных рассылок, количество клиентов
  - Лекторы (в планах) - количество всего вебинаров, количество проведенных вебинаров, количество участников в них, количество предстоящих вебинаров
- Есть быстрые действия которые также зависят от роли:
  - Пользователь - создать рассылку, сообщение, клиента
  - Менеджер - не имеет
  - Лектор (в планах) - создать вебинар, управление участниками (по отношению к вебинару), материалы вебинаров, расписание
- Для незарегистрированных пользователей отображается информация о планах воздействия на главной странице

### Сообщение
- Здесь можно искать сообщения по ключевым словам, фильтровать по статусу, также изображена статистика созданных сообщений, черновиков и активных
- Отображаются сообщения, которые были отправлены рассылкой, их можно изменить, удалить, создать рассылку (отправить) - доступно только пользователям
- На каждой карточке сообщений отображена информация о теме письма, тексте, дата создания, статус и в каких рассылках использован
  - Для менеджера изображен автор сообщения
#### Форма создания/изменения уведомления
- Можно написать тему и само сообщение, при создании сохраняется на странице черновиков в ожидании создания рассылки

### Клиенты
- Можно найти клиента по имени, почте и сообщению, фильтровать по наличию комментариев
- На карточке клиента отображено имя, почта, комментарий, дата создания ее можно изменить и удалить - для пользователя
#### Форма создания/изменение клиента
- На данной форме можно написать ФИО, почту и комментарий, предварительно отображается вид будущей карточки
- Также есть советы по заполнению
- При написании существующей почты выдает ошибку

### Рассылки
- Можно найти рассылку по имени, почте и сообщению
- Фильтровать по статусу создан, запущен, завершен, также изображена количество рассылок на кнопках
- В карточке отображена информация о теме, даты создания, количество получателей, само сообщение, период рассылки, кто получатели
  - Для менеджера - кто автор
- По цвету карточки можно определить статус где: оранжевая является созданной, зеленная - запущенной и серая - завершенной
- Каждую карточку можно изменить, удалить и отправить заново (если карточка является созданной) - только пользователям
- Также можно перейти на страницу логов карточки рассылки - только пользователи

#### Форма создания/изменения рассылки
- Можно установить дату и время начала и конца путем изменения в календаре
- Можно установить статус рассылки создана/запущена/завершена
- Выбрать одно из созданных сообщений, либо создать новое
- Выбрать получателей и создать нового клиента
- Снизу находится предварительный вид рассылки
- После создания рассылки сообщение перемещается в "Использованные"
- Логи создаются автоматически при каждой попытке отправки

### Логи
- Можно найти лог по номеру рассылки и названию темы
- Есть фильтр на успешные и ошибочные логи, на них изображено количество логов
- Карточка лога показывает номер рассылки, тему, дату и время, дает ссылку на рассылку, успешность
- Через карточку можно перейти на рассылку, кнопка подробнее дает информацию о будущих обновлениях, кнопка повтор, пока не активна
- При фильтровании логов по рассылке появляется информация о фильтре: тема, период и статус рассылки

### Удаление клиента, сообщение, рассылки
- Высвечивается окно подтверждения и переводит на шуточную страницу подтверждения удаления
- При удалении клиента, сообщения, те пропадают со своих страниц и нельзя будет выбрать при создании рассылки
- При удалении рассылки вместе с ней удаляются и логи

## Часть 2 - Пользователи

### Регистрация
- Все просто, вводим данные: ФИ, почта, пароль, номер телефона необязательное поле
- Можно выбрать роль Пользователя и Лектора
- Можно зарегистрироваться, либо перейти на форму входа

#### Вход
- Вход осуществляется вводом почты и пароля
- Если пользователь/лектор/менеджер забыли пароль, можно его восстановить

#### Выход
- Страница предупреждает и требует подтверждение, либо можно перейти на главную страницу 

#### Восстановление пароля
1. ввод почты для получения сообщение кода 
2. вводим код
3. обновляем пароль

### Пользователь
- Может создавать и редактировать сообщения, рассылки, клиентов
- Клиент самостоятельная сущность (создает(приглашает) один пользователь, а видят и пользуются все)

### Менеджер
- Может просматривать рассылки, сообщения, клиентов (в будущем - пользователей)
- Следит за порядком

### Лектор
- Данная роль в разработке
