# Проект по создании почты для рассылки

### Что здесь есть на данном коммите:
- Страницы: Главная, Уведомлений, Клиентов, Рассылок, Логов, формы создания/регистрации клиентов, сообщений, рассылок
- Меню для перехода между страницами сайта
- Адаптивный дизайн для мобильных устройств
- 

### Главная
- Здесь есть приветствие
- Отображается сколько всего рассылок, сколько активных и сколько клиентов зарегистрировали
- Есть быстрые действия где можно перейти на форму создания/регистрации клиента, сообщения, рассылки
- Есть информация о пройденной работе и планируемые следующие действия по отношению к этому сайту

### Уведомления
- Здесь отображается сколько сообщений было создано
- Отображаются сообщения, которые были отправлены рассылкой, их можно изменить, удалить, создать рассылку (отправить)
- Можно с этой страницы перейти на страницу черновиков, где находятся сообщения не участвовавших в рассылках, их также можно отправить, изменить, удалить
- На каждой карточке сообщений отображена информация о теме письма, тексте, дата создания, статус и в каких рассылках использован

#### Форма создания/изменения уведомления
- Здесь можно написать тему и само сообщение, при создании сохраняется на странице черновиков в ожидании создания рассылки


### Клиенты
- На данной странице отображено сколько клиентов было создано 
- Можно найти клиента по имени, почте и сообщению
- Можно отфильтровать все клиенты и с сообщениями
- На карточке клиента отображено имя, почта, комментарий, дата создания ее можно изменить и удалить

#### Форма создания/изменение клиента
- На данной форме можно написать ФИО, почту и комментарий, предварительно отображается вид будущей карточки
- Также есть советы по заполнению
- При написании существующей почты выдает ошибку

### Рассылки
- Здесь видно сколько рассылок было создано и сколько активных
- В карточке отображена информация о теме, даты создания, количество получателей, само сообщение, период рассылки, кто получатели
- По цвету карточки можно определить статус где: оранжевая является созданной, зеленная является запущенной и серая является завершенной
- Каждую карточку можно изменить, удалить и отправить заново (если карточка является созданной)
- Также можно перейти на страницу логов карточки рассылки
- Снизу видна предварительная

#### Форма создания/изменения рассылки
- Можно установить дату и время начала и конца путем изменения в календаре
- Можно установить статус рассылки создана/запущена/завершена
- Выбрать одно из созданных сообщений, либо создать новое
- Выбрать получателей и создать нового клиента
- Снизу находится предварительный вид рассылки
- После отправки рассылки сообщение перемещается в "Использованные"
- Логи создаются автоматически при каждой попытке отправки

### Логи
- Отображено количество логов и количество успешных и ошибочных
- Можно найти логи по номеру рассылки и названию темы
- Есть фильтр на успешные и ошибочные логи
- Карточка лога показывает номер рассылки, тему, дату и время, дает ссылку на рассылку, успешность
- Через карточку можно перейти на рассылку, кнопка подробнее дает информацию о будущих обновлениях, кнопка повтор, пока не активна
- При фильтровании логов по рассылке появляется информация о фильтре: тема, период и статус рассылки

### Удаление клиента, сообщение, рассылки
- Высвечивается окно подтверждения и переводит на шуточную страницу подтверждения удаления
- При удалении клиента, сообщения, те пропадают со своих страниц и нельзя будет выбрать при создании рассылки
- При удалении рассылки вместе с ней удаляются и логи
